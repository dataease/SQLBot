# Triage Labels

工程技能的五个角色映射如下：

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给 Agent 实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

GitHub 使用上表对应标签；TAPD 的任务标签字段可用时，使用同名角色标签，
并回读核对。若只能在正文标记角色，交付时说明，不能声称已设置平台标签。
已有业务标签继续保留。

`ready-for-agent` 表示规格已具备交接条件，不代替当前任务的实施授权；
有前置任务时，仍需确认阻塞项已完成。研究记录或尚未选定方案的内容不标为可直接实施。
